# LeetCode

My solutions to [LeetCode](https://leetcode.com/) problems, written in Python.

Each solution comes with unit tests and a README explaining my approach, the time and space complexity, the LeetCode result and what I learned from the problem.

## Structure

```text
python/
└── easy/
    └── 0001-two-sum/
        ├── solution.py        # The solution submitted to LeetCode
        ├── test_solution.py   # Unit tests using unittest
        └── README.md          # Approach, complexity and what I learned
```

Problems are grouped by language and difficulty, and each folder is named after the problem number and title.

## Running Tests

The tests use Python's built-in `unittest` framework, so no extra dependencies are needed.

Run the tests from inside a problem folder:

```bash
cd python/easy/0001-two-sum
python -m unittest -v
```
